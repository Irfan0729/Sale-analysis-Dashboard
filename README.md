# Sales Analysis Dashboard – Excel

## Project Overview
This project is an interactive **Sales Analysis Dashboard built using Microsoft Excel** to analyze revenue, customer spending, order delivery time, product performance, and sales trends. It provides a visual summary of business performance through charts, KPI cards, and interactive filters.

## Dashboard Highlights
- **Total Orders:** 1,000
- **Total Revenue:** $3,520,984.00
- **Average Order Delivery Time:** 5.53
- **Average Customer Spend:** $3,520.98

## Key Features
- **Revenue by Occasion:** Analyzes revenue generated from occasions such as anniversaries, birthdays, Diwali, Holi, and Valentine's Day.
- **Revenue by Category:** Compares revenue across product categories, including colors, mugs, raksha bandhan, soft toys, and sweets.
- **Revenue by Hour:** Visualizes order activity at different hours of the day.
- **Revenue by Month:** Identifies monthly revenue trends and seasonal patterns.
- **Top 5 Products by Revenue:** Highlights the highest-performing products.
- **Top 10 Cities by Orders:** Examines order distribution across different cities.
- **Interactive Occasion Filter:** Allows users to filter dashboard results by occasion.

## Tools and Technologies

## Project Objective
The objective of this project is to transform raw sales data into meaningful business insights, identify high-performing products and occasions, understand monthly revenue trends, and support data-driven decision-making.

## Key Learnings
- Data cleaning and organization
- Creating KPIs for business performance
- Building interactive Excel dashboards
- Analyzing revenue and order trends
- Presenting insights through visualizations

## Conclusion
This project demonstrates how Microsoft Excel can be used to build an interactive sales dashboard and convert business data into clear, actionable insights. It is a practical project for developing data analytics and business intelligence skills.
